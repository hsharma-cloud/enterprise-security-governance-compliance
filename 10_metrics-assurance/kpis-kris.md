# Key Performance Indicators (KPIs) and Key Risk Indicators (KRIs)

## Purpose

This document defines the key performance and risk indicators used to measure security effectiveness and exposure across the environment.

---

## Scope

This applies to all security domains, including identity, vulnerability management, security operations, network security, and data protection.

---

## Objectives

- Measure performance of security controls and processes
- Identify and monitor security risks
- Support decision-making and prioritization
- Provide visibility into security posture

---

## Definitions

| Type | Description |
|------|------------|
| **KPI (Key Performance Indicator)** | Measures effectiveness and performance of controls |
| **KRI (Key Risk Indicator)** | Measures exposure to risk and potential impact |

---

## Key Performance Indicators (KPIs)

### Identity and Access

- Access review completion rate
- Number of inactive accounts removed
- Percentage of systems using strong authentication

---

### Vulnerability Management

- Percentage of vulnerabilities remediated within SLA
- Average time to remediate vulnerabilities
- Scan coverage across systems

---

### Security Operations

- Mean time to detect (MTTD)
- Mean time to respond (MTTR)
- Alert investigation rate

---

### Network Security

- Firewall rule review completion rate
- Number of blocked unauthorized connections
- Segmentation compliance rate

---

### Data Protection

- Encryption coverage percentage
- Data access monitoring coverage
- DLP policy enforcement rate

---

## Key Risk Indicators (KRIs)

### Identity and Access

- Number of privileged accounts
- Number of failed authentication attempts
- Number of orphaned or inactive accounts

---

### Vulnerability Management

- Number of critical vulnerabilities
- Number of overdue vulnerabilities
- Percentage of systems not scanned

---

### Security Operations

- Number of unresolved high-severity alerts
- Alert backlog volume
- Detection gaps identified

---

### Network Security

- Number of misconfigured firewall rules
- Unauthorized access attempts
- Unmonitored network segments

---

### Data Protection

- Number of data access violations
- Unencrypted data stores
- Data transfer anomalies

---

## Monitoring and Reporting

- KPIs and KRIs are tracked regularly
- Trends are analyzed to identify improvements or risks
- Reports are generated for operational and management review
- Metrics are used to drive decision-making

---

## Risk Considerations

- Lack of KPIs reduces visibility into performance
- Missing KRIs hides potential risk exposure
- Poor tracking limits effective decision-making
- Inconsistent reporting reduces accountability
